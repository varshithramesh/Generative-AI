## 📚 Assignments

### 1. Understanding Generative and Discriminative Models Using MNIST

This assignment explores the difference between a **discriminative
model** and a **generative model** using the MNIST handwritten digit
dataset.

Only the digits **0 and 1** are selected.

-   **Discriminative model:** Logistic Regression
-   **Generative model:** Autoencoder
-   **Dataset:** MNIST
-   **Input:** 28 × 28 handwritten digit images
-   **Classes:** 0 and 1

The Logistic Regression model achieved **99.95% accuracy** on the test
data. The Autoencoder was used to learn a compressed representation of
the images and reconstruct digit-like images.

**Notebook:**
`Understanding Generative and Discriminative Models Using MNIST Vars.ipynb`

------------------------------------------------------------------------

### 2. Exploring Text Generation Using GPT-2

This assignment studies how different text-generation parameters affect
the output of a pretrained **GPT-2** language model.

The same opening prompt is used across experiments:

> "The young scientist entered the abandoned laboratory and discovered"

The following parameters are explored:

  Experiment   Parameter              Value Main Effect
  ------------ -------------------- ------- -----------------------------------
  1            Temperature              0.5 More focused and predictable text
  2            Top-k                     10 More controlled word selection
  3            Top-p                    0.7 Controlled but descriptive output
  4            Repetition Penalty       1.5 More varied wording
  5            Temperature              1.5 More random and unusual output

A custom smart-water-bottle prompt is also tested with different
settings.

**Notebook:** `Text Generation Assignment 2 varshith.ipynb`

------------------------------------------------------------------------

### 3. Identifying Bias in a Pretrained Generative AI Model

This assignment investigates how bias or stereotypical patterns may
appear in outputs generated by a pretrained language model.

GPT-2 is prompted with neutral statements involving different
professions and roles:

-   Doctor
-   Nurse
-   Business Executive
-   Scientist
-   Police Officer
-   Criminal

For each profession, multiple outputs are generated and collected in a
Pandas DataFrame. The notebook also includes a simple analysis of
**male-associated and female-associated words** and an observation table
covering:

-   Gender patterns
-   Age patterns
-   Clothing
-   Professional appearance
-   Language / tone

The purpose is to observe whether the model produces noticeably
different patterns for different professions and to understand why
generated text should be evaluated critically rather than assumed to be
neutral.

**Notebook:** `GenAI assigment 3 varshith.ipynb`
